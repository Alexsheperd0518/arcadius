# 🌐 Arcadius Website

**Arcadius** is a sleek and modern **static website** built using **HTML**, **CSS**, and the **W3.CSS framework**. 
It showcases clean design principles, and intuitive structure, ideal for presenting digital content, gaming platforms, portfolios, or personal projects.

--------------------------------------------------------------------------------------------------------------------------------------------------------

## 🛠️ Tech Stack

- **HTML5** – Semantic structure and accessibility  
- **CSS3** – Custom styling and layout  
- **W3.CSS** – Lightweight and responsive UI framework

--------------------------------------------------------------------------------------------------------------------------------------------------------

## 🚀 Features

- Fully static front-end with zero dependencies  
- Clean and minimal design aesthetics  
- Optimized layout using the W3.CSS grid system  
- Fast loading and cross-browser compatible
